Find the way out of a container before someone else does.

A single bash script runs inside a Docker or Kubernetes container and reports every viable escape vector — 51 checks plus a config-driven CVE engine. It makes no changes to the system. Built for penetration testers and security teams running real assessments.

Nine surfaces an attacker would probe first.

Each check maps to an established escape primitive — privileged config, capability abuse, namespace breakout, mount exposure, kernel surface, Kubernetes RBAC, cloud metadata theft, container-runtime escape, and kernel hardening posture.

01 / configuration

Privileged mode

Detects --privileged containers and the full capability set that comes with them — the single fastest path to host root.

Every finding is a self-contained briefing.

No raw flags to decode. Each result tells you what it is, what an attacker does with it, how hard that is, and exactly how to close it — ready to paste into a report.

CRITICALCVE-2026-31431
What it isAF_ALG socket family reachable; the authencesn AEAD algorithm can be bound and spliced.
ImpactControlled 4-byte writes into the page cache of any readable setuid binary → root.
ExploitabilityTrivial. A ~732-byte Python PoC achieves root reliably. No capabilities required. On CISA KEV.
RecommendationApply distro kernel patches. Interim: unload algif_aead, block AF_ALG via seccomp.

Severity that reflects reality

A single CRITICAL is generally enough for full host compromise. But findings combine — a MEDIUM seccomp gap alongside a HIGH capability becomes a practical escape path the tool flags accordingly.

CRITICALHost escape likely with minimal effort.
HIGHExploitable with moderate effort or in combination.
MEDIUMDefence-in-depth gap; raises other findings' risk.
INFORecorded for context and cross-referencing.

Two files, same directory, one run.

The script and its CVE database sit side by side. Output goes to a timestamped report — or JSON for piping into CI, SIEM, or jq.

bash
# pull the script and its CVE database curl -O https://raw.githubusercontent.com/liamromanis101/K8s-container_escape_audit/main/container_escape_audit.sh curl -O https://raw.githubusercontent.com/liamromanis101/K8s-container_escape_audit/main/cve_checks.conf chmod +x container_escape_audit.sh # standard run — writes a timestamped report ./container_escape_audit.sh # JSON out, filter to CRITICAL findings only ./container_escape_audit.sh --json --no-report | jq '.findings[] | select(.severity=="CRITICAL")'
// get started
